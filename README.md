# AI-Powered Web Application Landing Page

This project is a front-end implementation of an AI-powered web application landing page, developed as part of a job interview task assessment. The design is pixel-perfect, fully responsive, and includes a functional chat box as per the requirements.
Project Overview

The goal was to recreate a provided Figma design with precision, ensure responsiveness across devices, and deploy the application on a hosting platform. The project adheres to best practices, clean architecture, and includes error handling where necessary.
Tools and Packages Used

## Tools and Packages Used

HTML5: For semantic structure.
CSS3: For styling, including media queries for responsiveness.
JavaScript: For interactivity, particularly the functional chat box.
React: Used for building reusable components and managing state.
Tailwind CSS: For rapid, utility-first styling aligned with the Figma design.
Vite: For fast development and optimized build process.
ESLint: For maintaining code quality and consistency.
Vercel: For deployment and hosting the live application.
Git: For version control.

### Project Setup Instructions

1. **Clone the Repository**

````bash
git clone https://github.com/mehedi8430/ai-coach-landing.git
cd ai-coach-landing

2. **Install Dependencies:Ensure you have Node.js installed, then run:**
```bash
npm install

3. **Run the Development Server:**
```bash
npm run dev

4. **Open http://localhost:5173 in your browser to view the application.**

5. **1. **Build for Production:**
```bash
npm run build

1. **Preview the Production Build:**
```bash
npm run preview
````
